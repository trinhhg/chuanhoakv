Chuẩn hóa schema đơn hàng

Dán JSON KV (mảng order) vào ô bên dưới. Tool sẽ áp schema cố định lên từng đơn, tô màu theo mức độ thiếu/sai, cho sửa trực tiếp trong bảng, rồi xuất lại JSON chuẩn. Đã bỏ 2 cột trùng lặp/không dùng tới trong code (dateCreated, daysLeft) — 4 file code chỉ đọc date (chuỗi hiển thị) và createdTs (epoch ms) để tính thời gian, còn dateCreated không được đọc lại ở đâu và daysLeft luôn được tính lại tại chỗ chứ không lưu. "Chuẩn hóa ngày giờ" gộp mọi kiểu cũ (HH:MM:SS DD/MM/YYYY, DD/MM/YY HH:MM, ISO, epoch...) trong 2 cột date và fulfilledAt về đúng 1 kiểu DD/MM/YYYY HH:MM.
